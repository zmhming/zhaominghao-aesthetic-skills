# 宣传核查

目的是帮助读者识别一句话能成立到哪里，不判断创作者内心动机，也不因为它来自营销账号就判假。以下是核查模式，不是任何具体项目的预设医学结论。

## 从原话到可查证问题

保留必要原话，拆开事实、价值判断与购买催促。例如一句话同时包含“能改善”“优于其他方法”“持续多年”“适合所有人”，需要分别查证，不能用一项研究整体背书。

结论可用“有相应支持”“部分成立，但扩大了适用范围/效果”“关键资料不足，暂不能判断”“与已核实证据不符”。根据证据写原因，不用打分制造精确感。没有证据支持与已有证据反驳必须分开；属于审美或价值取舍的部分，不能靠论文替读者决定。

多条主张可用四列：原话｜目前能支持到哪里｜缺失或被混淆的信息｜这对选择有什么影响。单条主张用几段白话即可。

## 常见偷换与核查方向

| 表述方式 | 核查重点 |
| --- | --- |
| “刺激胶原，所以年轻十岁” | 机制是否有人体临床结果支持；测量的是否为读者关心的外观改善；“十岁”如何定义 |
| “有效率 95%” | 什么算有效、谁评分、分母、对照、时间、失访、真实改善幅度；不能只转述百分数 |
| “天然、自体、无创、可吸收，所以绝对安全” | 材料来源和操作类别不能自动推出安全；核对实际常见反应与严重风险 |
| “一次永久，零恢复期” | 随访长度、维持定义、再次治疗和恢复指标；绝对词需要相应证据 |
| “获批/认证，效果有保证” | 具体监管动作、地区、对象和用途；不能从上市资格推出优越性、无风险或个人保证 |
| “某医生/明星都做”“几百张案例图” | 是临床经验、推荐还是研究；有无分母、未改善者、共同治疗和选择偏倚 |
| “术前术后差异很大” | 光线、角度、焦距、表情、妆容、修图、时间、肿胀和其他治疗是否可比；不可比不自动证明造假 |
| “研究证明 A 比 B 好” | 是否头对头、同一目标与时点、相同人群和评估方式；不同研究数字不能直接排名 |
| “越早做越省钱”“不做就来不及”“只剩今天” | 是否有真实医学时机证据；商业截止时间不等于医学紧迫性 |
| “所有医美都是骗局/必然毁容” | 同样要求可核实证据，避免用恐惧替代营销；区分项目、适应证和实际风险 |

## 对结论进行校正

不要只说“营销话术”“智商税”“割韭菜”。指出具体缺口，并把原话改写成证据允许的有限表述。改写需保留真实不确定性，不把广告换成另一种过度肯定。

不要为了显得客观，给无依据的极端说法一半篇幅或强行各打五十大板。对有效果但利益有限的项目，可同时承认有效性与预期边界。经济价值取决于本人目标、负担、可接受风险和替代办法，不能只凭单价或研究标签宣判“值不值”。

结束时给出下一步最有用的核实问题，例如：宣传对应哪一种具体产品与用途；效果由什么指标、在多久后测量；可能无法改善的部分是什么；出现不满意或并发症如何处理。避免以“赶紧预约”“私信我”结束。
