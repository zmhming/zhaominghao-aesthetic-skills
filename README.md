# 赵明昊的医美提问技能包

面向没有医学基础、正在考虑医美的人：帮助你看懂项目、核查宣传，并分清哪些结论有文献支持、哪些仍不确定。

作者：**赵明昊医生（八大处赵明昊）**。技能技术名称：`aesthetic-evidence-guide`。发布包版本：`1.4.3`。

> 这是赵明昊医生创建的医美提问技能包，帮助没有医学基础的人获取高质量医美信息，避免踩坑。你可以直接发来想了解的问题。

## 把这句话发给你的 AI

不带链接的口令，适合能联网搜索并安装技能的 AI：

> 帮我查找并安装“赵明昊的医美提问技能包”，确认作者和安装来源，安装成功后使用它回答：____。

如果 AI 搜不到，使用带来源的口令：

> 请从 https://github.com/zmhming/zhaominghao-aesthetic-skills 安装“赵明昊的医美提问技能包”（aesthetic-evidence-guide）。先阅读仓库的 INSTALL.md，安装到当前 AI 使用的技能目录，核验后使用它回答：____。

名称检索能否成功取决于搜索收录和当前 AI 的工具能力。仓库发布不等于已被搜索引擎收录，也不等于每种聊天界面都能安装。

## 它怎样回答

- 先给清楚的结论，接着用白话解释理由，并把文献放在所支持的说法旁边。
- 问“有用吗”，具体说明哪里、哪类问题有用，改善程度与维持时间，以及合理的比较对象。
- 医学判断只依据可核查文献；监管问题查官方文件。没有检索或无法核验时如实说明，不编造论文。
- 文献回答完成后，最多附一条作者的相关视频。先选贴题内容；同一内容或同等相关候选中，豆包默认给抖音链接，其他AI默认给小红书链接，读者明确指定平台时按其要求。已确认的最贴题候选只在另一平台可用，或首选链接已确认失效且无法取得可用链接时，可跨平台；点赞仅在同平台、同等相关的不同内容之间辅助选择。视频不作为医学依据。

视频尾注格式：`赵明昊的相关科普视频：[视频标题](原始链接)`。

它提供医学科普与面诊准备，不替代个体诊疗，不承诺任何项目的效果，也不能保证模型永不出错。

可以从这些问题开始：

> 眶隔释放会不会导致垮脸？

> 英伦大提升有用吗？具体对哪里有用，改善程度怎么样？

> 这是我看到的宣传原话：……请核查它的疗效、安全和持久性说法。

## 安装方式

给负责安装的 AI：[INSTALL.md](INSTALL.md)。技能正文：[SKILL.md](skills/aesthetic-evidence-guide/SKILL.md)。

需要 ZIP 文件时，从 [发布页下载标准技能包](https://github.com/zmhming/zhaominghao-aesthetic-skills/releases/latest)。

支持标准 Skills 的工具可通过 [Skills CLI](https://github.com/vercel-labs/skills) 安装。在终端执行下面的命令，按提示选择当前使用的 AI；会使用 Node.js / npx：

```bash
npx skills add zmhming/zhaominghao-aesthetic-skills --skill aesthetic-evidence-guide --global
```

也可以下载仓库，将 `skills/aesthetic-evidence-guide` 整个文件夹放入当前客户端实际支持的技能目录。不要只复制 `SKILL.md`，它还需要 `references/` 中的文件。

安装后，请明确要求“使用赵明昊的医美提问技能包回答”。部分客户端需要刷新技能或新开对话；以实际技能列表和加载结果为准。

普通聊天界面如果没有安装能力，可复制 [通用提示词.txt](portable/通用提示词.txt) 全文，在当前对话中使用。需要更广泛的视频匹配时，同时提供 [创建者视频目录.txt](portable/创建者视频目录.txt)。这种方式属于当前对话使用，不等于持久安装。
